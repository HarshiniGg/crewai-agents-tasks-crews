# CrewAI Agents Tasks Crews

## Overview

This project demonstrates the core concepts of CrewAI including Agents, Tasks, and Crews. The project was created as part of the CrewAI Hands-on Topic 2 assessment.

## Objectives

* Understand Agents, Tasks, and Crews
* Learn CrewAI workflow orchestration
* Create role-based agents
* Execute multi-agent task workflows

## Technologies Used

* Python
* CrewAI
* YAML Configuration
* OpenAI API

## Steps Followed

1. Installed CrewAI and required dependencies.
2. Created multiple agents with roles and goals.
3. Defined tasks for each agent.
4. Connected tasks and agents inside a crew workflow.
5. Executed the workflow successfully.
6. Verified outputs generated by agents.

## Problems Faced

* YAML indentation errors
* Agent-task mapping confusion
* API key configuration issues
* Workflow execution errors

## Solutions

* Corrected YAML formatting
* Verified task connections properly
* Updated environment variables
* Tested the workflow step by step

## Outcome

Successfully implemented and executed a CrewAI workflow using Agents, Tasks, and Crews concepts.
